# Tienda Online

## Propósito de la página

Esta página web fue desarrollada como una tienda online de productos tecnológicos.  
El objetivo es permitir que los usuarios visualicen productos, agreguen artículos al carrito y finalicen una compra mediante un formulario interactivo.

El público objetivo son personas interesadas en productos tecnológicos como audífonos, smartwatch y accesorios gamer.

---

# Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

---

# Semántica HTML aplicada

Para mejorar la organización y estructura de la página se utilizaron etiquetas semánticas de HTML5 como:

- `<header>` → Encabezado principal
- `<nav>` → Menú de navegación
- `<main>` → Contenido principal
- `<section>` → Secciones de contenido
- `<article>` → Productos individuales
- `<footer>` → Pie de página

Esto permite una estructura más clara y facilita la comprensión del contenido.

---

# Accesibilidad implementada

Se aplicaron diferentes características de accesibilidad:

- Uso de atributos `alt` en imágenes.
- Uso de etiquetas `<label>` en el formulario.
- Uso de `aria-label` en botones importantes.
- Navegación compatible con teclado.
- Contraste adecuado de colores.
- Indicadores visuales al usar TAB (`focus`).

---

# Funcionalidades principales

- Visualización de productos tecnológicos.
- Carrito de compras dinámico.
- Cálculo automático del total.
- Validación de formulario.
- Navegación entre productos y formulario de compra.
- Diseño responsive para dispositivos móviles.

---

# Cómo visualizar la página

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo `index.html` en cualquier navegador web.
